# Damas em Python

Jogo simples de damas para dois jogadores no mesmo notebook, usando mouse.

## Como instalar

1. Instale o Python 3 pelo site oficial: https://www.python.org/downloads/
2. Abra o PowerShell nesta pasta.
3. Instale a biblioteca:

```powershell
python -m pip install -r requirements.txt
```

## Como jogar

```powershell
python damas.py
```

As brancas comecam. Clique na peca da sua vez e depois na casa de destino. A captura e obrigatoria; quando houver outra captura com a mesma peca, a jogada continua automaticamente. Uma peca que chega ao outro lado vira dama e passa a se mover nas quatro diagonais.

Pressione `R` para reiniciar a partida ou feche a janela para sair.
